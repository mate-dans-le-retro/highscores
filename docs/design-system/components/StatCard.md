The statistic tile at the top of a tournament: icon in a pill, label in `eyebrow`, value, optional hint.

Pass `numeric` when the value is a number that refreshes — sign-up counter, score, timer. The value then becomes monospaced so the digits do not jump from one refresh to the next.

Write labels in singular or plural depending on meaning, without a colon: « Joueurs inscrits », « Format », « Lieu », « Début ». The style puts them in uppercase.

Use `hint` for the secondary detail that goes with a value — « 4 joueurs/match » under the format.

Line up four tiles at most on a row; beyond that, the eye no longer reads them at once.

The product provides the icon (Lucide, 2px stroke, 20px). A tile without an icon is still fine: do not invent a glyph to fill the pill.
